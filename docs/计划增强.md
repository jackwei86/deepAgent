# DeepAgent 增强：多用户素材库 + 同端口集成 + 参数化工具 + 桌面化（修订版）

> 批准日期：2026-09-10　　状态：已批准实施
>
> 背景：图像/视频任务链路（文字/语音 → LLM 意图识别 → 任务单 JSON → 命令行调用 C++ SDK → 进度反馈 → 结果预览）已全链路打通。本计划在其上增加多用户素材库、同端口集成界面、工具参数化与桌面化体验。

## ① 素材库目录：用户名一级分类（基础层）

目录结构：`E:\DeepAgent\media\<用户名>\image\` 与 `media\<用户名>\video\`

- `config.py`：`MEDIA_DIR` + 扩展名分类表 + `ensure_dirs()`
- 新增 `assistant/core/media.py`：
  - `user_media_root(user_name)`：用户名净化后生成 `media/<用户名>/`（保留中文/字母/数字/`-_`，其余转 `_`）
  - `classify(ext)` → `image` / `video`
  - `resolve_in_media(user_name, file_name)`：大小写不敏感地在 image/、video/、根目录匹配，支持子路径
  - `list_tree(user_name)`：树状数据

## ② 同 8080 端口集成（关键架构决策）

**自定义启动器** `assistant/run_webui.py`（替代直接跑 `open-webui serve`）：

```python
from open_webui.main import app          # Open WebUI 的 FastAPI 实例
app.include_router(media_api.router)     # 挂载 /media/api/*（树/上传/下载/删除/任务导入/工具说明）
app.mount("/media-ui", StaticFiles(...)) # 素材库+工具说明 单页界面
uvicorn.run(app, ...)                    # 同进程同端口
```

- 不改 Open WebUI 源码（site-packages），升级不丢，全部代码在我们仓库
- **鉴权复用**：素材库 API 以 `get_verified_user` 为依赖（Open WebUI 自带），页面同源读取登录态 → 顺带拿到**真实登录用户名**用于 ① 的用户名目录
- **入口**：Open WebUI 管理端配置一条 Markdown 公告（Banner）「📚 素材库与工具说明」链接到 `/media-ui/`（原生侧边栏为编译产物无法免重建注入；桌面壳阶段在壳侧边栏提供真入口）
- 素材库页面自带左侧栏：**素材树 Tab + 工具说明 Tab**（③）

## ③ 工具说明侧边栏 Tab

`GET /media/api/tool-docs`：同进程直读工具注册表（id/名称/描述/参数 schema），页面渲染成参数表格——**始终与实际注册的工具同步**，新增 C++ 工具后自动出现。

## ④ 工具改造：file_name + 关键词 + 全参数

- 4 个工具签名增加 `file_name`（composite 另加 `file_name2`=前景）与 `__user__`
- 附件解析优先级：**聊天附件 → 素材库 file_name（含"素材库/收藏夹/当前目录"语义）→ 报错提示**
- docstring 更新教会 LLM：**"素材库/收藏夹/当前目录" = 当前用户的 media 目录（image=图片区、video=视频区）**，提到这些词时直接传 file_name，不要求上传附件
- 参数全面暴露：beauty/video-beauty 增加 `denoise: bool = True`（原写死）、composite 增加 `center: bool = True`；docstring 写明取值范围与典型说法
- `install_tools.py` 重新注册
