## 2. 系统架构

```
┌─────────────────────────── 用户 ────────────────────────────┐
│   文字输入                     语音输入(麦克风按钮)              │
│                                     │                       │
│                                     ▼                       │
│                        Open WebUI STT(本地 faster-whisper)    │
└─────────────┬───────────────────────────────────────────────┘
              ▼
┌──────────────────────────────────────────────────────────────┐
│ Open WebUI (Python/FastAPI, http://127.0.0.1:8080)           │
│  · 多 LLM 接入配置(管理员界面, OpenAI 兼容端点)                  │
│  · 聊天/附件管理/UI 渲染                                        │
│  · DeepAgent Tools ×4 (assistant/tools/*.py)                  │
│      └─ assistant/core/tool_impl.py 共享执行流程                │
│           ├─ resolve_message_files  定位消息附件                │
│           ├─ task_manager.create_task  生成任务单 JSON ────────┼──► data/tasks/<id>/task.json
│           ├─ sdk_runner.run_task  子进程执行 + 进度解析          │
│           └─ upload_to_webui  结果回传预览                      │
└──────────────┬───────────────────────────────────────────────┘
               ▼ 命令行(需求5)
   E:\DeepAgent\cpp-sdk\build\Debug\deepagent-cv.exe run --task <task.json>
               │ stdout: JSON-lines 事件流
               ▼
   C++ SDK(OpenCV 4.6): beauty / matting / composite / video-beauty
```

### 关键数据流(任务单)

1. LLM 依据 Tools 的中文 docstring 进行 function calling，给出任务类型与参数；
2. `task_manager.create_task()` 探测素材元数据(CLI `info` 命令)后生成任务单(状态 `pending`)；
3. `sdk_runner` 以 `run --task` 启动 C++ CLI(状态 `running`)，逐行解析进度事件并节流落盘；
4. 完成后回写 `execution`(status/elapsed/result/logs)，产物在 `data/tasks/<id>/result.*`；
5. 结果上传 Open WebUI 文件 API，聊天中内联预览(图片 base64 + 文件直链)或播放链接(视频)。

## 4. C++ SDK(deepagent-cv)

### 4.1 接口层(模拟正式 SDK)

`cpp-sdk/include/deepagent/`：
- `progress.h` — `ProgressCallback(percent, stage)` / `LogCallback`，所有长耗时接口通过 `ProgressReporter` 上报；
- `beauty.h` — `BeautyParams{strength,denoise,whiten}`，`beautify_image / beauty_video`；
- `matting.h` — `MattingParams{mode(GRABCUT|CHROMA), rect, background}`，`matting_image`；
- `composite.h` — `CompositeParams{x,y,scale,center}`，`composite_image`(支持带 Alpha 前景)。

### 4.2 CLI 用法

```
deepagent-cv beauty    --input a.jpg --output b.jpg [--strength 0.7] [--denoise 1] [--whiten 0]
deepagent-cv matting   --input a.jpg --output b.png [--mode grabcut|chroma] [--background transparent|white|green]
deepagent-cv composite --base base.jpg --fg fg.png --output out.jpg [--x -1] [--y -1] [--scale 1.0]
deepagent-cv video-beauty --input a.mp4 --output b.mp4 [--strength 0.7]
deepagent-cv info      --input <file>          # 探测宽高/时长/帧率(任务单元数据)
deepagent-cv run       --task <task.json>      # 任务单模式(第三方工具对接入口)
```

### 4.3 JSON-lines 进度协议(stdout，UTF-8)

```json
{"event":"start","task":"video-beauty","input":"...","output":"...","task_id":"..."}
{"event":"progress","percent":35,"stage":"处理帧 88/250","task_id":"..."}
{"event":"log","message":"[12:23:22] 打开视频 1280x720@25fps 共150帧"}
{"event":"done","output":"...","elapsed_ms":29512,"exit_code":0}
{"event":"error","code":20,"elapsed_ms":1}
```

约定：`progress` 按需上报(视频每≥5%)；退出码 `0` 成功，`1` 用法错误，`20` 输入读取，`21` 输出写出，`22` 参数非法，`30/31` 任务单解析/类型不支持。

### 4.4 构建(VS2019 / v142 / x64 / Debug)

```bat
cd cpp-sdk\scripts
build_windows.bat [OpenCV目录]     :: 默认 D:\SDK\third-party\opencv4
```

工程要点(均已写入 CMakeLists 注释)：
- **仅 Debug 构建**(AGENTS.md)；链接 OpenCV 的 **Debug 导入库**——MSVC Debug/Release 的 `std::string` 布局不同(`_Container_base` 代理指针)，跨 DLL 传 `cv::String` 会错位，`cv::debug_build_guard` 即为此而设；
- `cmake/FindCUDA.cmake` 桩模块：本机多套 CUDA(11.6/11.8/12.1/12.3/12.8)与自定义 OpenCV 包的 `CUDA <ver> EXACT` 校验冲突，本项目不用 CUDA 故直接放行；
- 构建后自动复制 OpenCV Debug DLL 到 `build/Debug/`；
- `/utf-8` 保证中文进度与日志正确；
- G 盘 `openv4.11.0._install`(CUDA 12.8)因 `opencv_videoio4110d.lib` 为 0 字节且运行期字符串异常，弃用；如需 CUDA 版 OpenCV 请重新编译完整包后替换 `OpenCV_DIR`。

### 4.5 替换为正式 C++ SDK

1. 保持 CLI 与 JSON-lines 协议不变，用正式 SDK 重实现 `beauty/matting/composite/video-beauty` 四个子命令(算法调用换成正式 SDK 接口)；
2. 或：第三方工具直接消费任务单(见《任务信息JSON格式.md》§5)——读取 `inputs[].path` + `task.parameters`，产出写到 `output.path`，向 stdout 打印同样的事件协议即可被 `sdk_runner` 接管进度与状态回写；
3. 可执行文件路径通过环境变量 `DEEPAGENT_CV_EXE` 覆盖，无需改动 Python 层。

## 6. 部署与配置步骤

### 6.1 环境安装(一次性，`assistant/scripts/setup_env.bat`)

```bat
cd assistant\scripts && setup_env.bat
```
内容：`E:\DeepAgent\.venv`(Python 3.12) → **CUDA 12.8 版 torch**(`--index-url .../whl/cu128`，AGENTS.md 推荐 12.8；下载失败自动回退 CPU 版) → `open-webui`(torch 已满足故保留 CUDA 版) → `faster-whisper` + `nvidia-cublas-cu12/cudnn-cu12`(GPU 语音识别的 DLL) → `httpx`。
pip 缓存与 venv 均在 E 盘(C 盘仅剩 16GB)。

### 6.2 启动与初始化

```bat
assistant\start.bat        :: 打开 http://127.0.0.1:8080，首次创建管理员账号
python assistant\install_tools.py --token <管理员API密钥>   :: 注册 4 个工具
```

### 6.3 LLM 接入(需求2)

管理面板 → 设置 → 通用 → **外部连接** → 添加 OpenAI API：
填 §3 表格中的 Base URL 与对应 API Key → 保存后模型出现在聊天顶部切换器。
建议同时在"任务模型"中选择支持 function calling 的模型(如 deepseek-chat)。

### 6.4 语音输入(需求1)

设置 → 音频(Audio)：
- 语音转文字(STT)引擎：**本地(Local)**，模型如 `Systran/faster-whisper-base`(快)或 `large-v3`(准，首次从 `HF_ENDPOINT=https://hf-mirror.com` 镜像下载，已由 `start.bat` 设置)；
- GPU 可用时 faster-whisper 自动用 CUDA(`start.bat` 已将 pip 安装的 cuBLAS/cuDNN DLL 前置到 PATH)；
- 无 GPU 时自动回退 CPU，功能不变。

### 6.5 使用流程

1. 上传素材(图片/视频)到聊天输入框；
2. 文字："帮我把这张照片美颜一下，强度高一点" 或按麦克风说同样内容；
3. LLM 自动调用对应工具 → 聊天中显示实时进度("视频美颜 35%｜处理帧 88/250")；
4. 完成后图片直接内联预览(合成/抠图效果可见)，视频显示播放/下载链接；
5. 每次执行的任务单归档在 `data/tasks/<task_id>/task.json`，可复查/重放。

## 7. CUDA 加速说明

| 组件 | 方案 | 说明 |
|---|---|---|
| torch(向量/嵌入等) | cu128 轮子 | RTX 4060 8GB；先装 torch 再装 open-webui 防降级 |
| faster-whisper(语音) | GPU + cuBLAS/cuDNN | `pip install nvidia-cublas-cu12 nvidia-cudnn-cu12`，`start.bat` 处理 DLL 路径 |

## 9. 已知限制与后续规划

1. `origin.input_type` 默认 `text`：Open WebUI 未向 Tool 透传"语音/文字"标记；语音链路已通，标记可后续通过前端小改或 Valve 手动切换；
2. 语音转写文本即 `origin.user_text`，原始音频不归档；
3. 视频预览为播放链接(浏览器打开)；如需聊天内嵌播放器，可小改 Open WebUI 前端 `FileItem` 组件；
4. Debug 构建 + Debug OpenCV DLL 性能低于 Release(演示可接受)；正式交付若允许 Release，去掉映射注释即可提速；
5. 后续可扩展：任务队列并发执行、更多算法(超分/去噪/风格化)、任务单 HTTP 推送给远程第三方执行器、历史任务面板。

### 10.1 多用户素材库

- 目录：`media/<用户名>/image|video`，对话中"**素材库 / 收藏夹 / 当前目录**"即指当前登录用户的该目录；
